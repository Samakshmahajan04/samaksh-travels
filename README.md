# Samaksh Travels website

Static site (no build step). Open `index.html`, or run `python3 -m http.server` in this folder.

- **Contact details:** `CONFIG` at the top of `js/main.js`. Logo files: `logo.svg` (mark), `logo-full.svg` (lockup).
- **3D scene / vehicles:** `js/scene.js` (procedural Three.js models: plane, train, helicopter, cab, tempo traveller, hotel).
- **Copy, sections:** `index.html`. **Colours / type:** tokens at the top of `css/styles.css`.
- Needs internet for the CDN libraries (Three.js, Lenis) and Google Fonts.
