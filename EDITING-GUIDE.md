# How to update your website (no coding needed)

1. Open this folder in Claude Code (desktop app → Code tab → choose this folder).
2. Tell Claude what you want, e.g. "change the phone number", "add a new destination Goa", "launch packages".
   Claude reads `CLAUDE.md` first, so short requests are enough.
3. Say "publish it". Claude commits and pushes; the live site updates in about a minute.

Cheap-edit tips: ask for one change at a time; name the section ("in the FAQ…").

## Backup & ownership
Everything is stored on GitHub: https://github.com/Samakshmahajan04/samaksh-travels (full history, you can roll back any change).

## Custom domain (when bought)
Add the domain in the repo's Settings → Pages, and add the DNS records at your domain seller (ask Claude for the exact list).
